# V20 notes

V20 продолжает V18, но заменяет 2D head-offset на world-locked виртуальную плоскость.

Главная идея: при первом стабильном ARKit кадре сохранить мировую позицию и ориентацию виртуального браузера, а затем каждый кадр проектировать его 3D-точки в текущий экран. Это даёт ожидаемое поведение AR-очков: повернул голову — виртуальный экран остался в пространстве.

Для взаимодействия panel transform теперь учитывается при переводе fingertip screen point обратно в координаты WKWebView.
