# HandAR Vision V18

## Архитектура

`RealityKit ARView` показывает live passthrough задней камеры и использует тот же `ARSession` для world tracking. `ARSessionDelegate` отдаёт `capturedImage` в Vision для hand tracking.

Виртуальный браузер остаётся UI-слоем поверх ARView. Для режима очков используется две синхронизированные поверхности WKWebView, но пользователь видит их как одну плавающую браузерную панель: без внутренних заголовков и обычной мобильной панели браузера.

## Управление

Указательный палец — курсор.
Pinch указательного и большого пальца — клик.
Удерживать pinch и вести вверх/вниз — scroll/drag.
Pinch обеими руками — CENTER.
Pinch возле левого/правого края landscape-экрана — LEFT/RIGHT.
Клавиатура iOS открывается при фокусе на обычном поле ввода сайта.

## Ориентация

Приложение принимает portrait и landscape. ARKit сам ведёт камеру, а Vision получает ориентацию через `CGImagePropertyOrientation`. Позиция курсора переводится из нормализованных координат камеры через `ARFrame.displayTransform(for:viewportSize:)`.

`ARCamera.projectPoint` не используется для Vision-координат, потому что этот API ожидает 3D-точку в мировых координатах. Для 2D точек камеры нужен display transform.

## Ограничения

Телефонная камера остаётся монокамерой. Разделение на два глаза относится к виртуальной панели браузера, а не к двум независимым оптическим перспективам реального мира.
