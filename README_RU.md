# HandAR Vision — V18 AR Glasses

V18 переделан вокруг одного понятного сценария: **главное меню → одна кнопка → погружение в AR**.

В AR-режиме нет постоянной панели управления, адресной строки и кнопок. Задняя камера работает как passthrough-фон, а браузер выглядит как одна виртуальная панель для двух глаз: содержимое синхронизировано, края скрыты маской под линзы, а панель двигается относительно движения телефона.

## Что изменилось

- главное меню содержит только название и кнопку **ВОЙТИ В AR**;
- AR запускается только после нажатия этой кнопки;
- вместо старого AVCapture preview используется **RealityKit ARView + ARWorldTrackingConfiguration**;
- Vision получает кадры прямо из AR-сессии;
- браузер больше не имеет отдельных LEFT/RIGHT заголовков и верхней панели — это одна логическая браузерная сцена, отображаемая в двух глазах;
- две стороны синхронизируют переходы и вертикальную прокрутку;
- добавлена маска под две линзы и небольшой межглазный разнос виртуальной панели;
- head tracking теперь берётся из ARKit, поэтому есть не только поворот, но и реакция на физическое перемещение телефона;
- ориентация поддерживает portrait и landscape и переводит изображение камеры через ARKit display transform, чтобы горизонтальный телефон не показывался как вертикальный;
- курсор один — по указательному пальцу обнаруженной руки;
- pinch = клик, удерживаемый pinch + движение вверх/вниз = прокрутка/перетаскивание;
- pinch обеими руками одновременно = CENTER / повторное центрирование AR-сцены;
- pinch у крайней левой или правой границы в landscape = LEFT / RIGHT, смещение виртуального браузера;
- обычный iOS keyboard появляется при фокусе на поле ввода внутри страницы.

## Важно

Это уже AR-сценарий с ARKit world tracking и passthrough-камерой, но это всё ещё прототип интерфейса под телефонные VR-очки: камера одна, поэтому это не настоящая физическая стереокамера и не самостоятельный 6DoF-рендер двух разных перспектив камеры.

Сборка IPA выполняется GitHub Actions на macOS. Физический запуск на iPhone здесь не заявляется без реального теста на устройстве.
