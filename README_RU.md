# HandAR Кинотеатр (HandARCinema)

Отдельное приложение: личный кинотеатр в VR-шлеме. Якорем служит ARKit, поэтому
зал появляется прямо в комнате, где ты сидишь.

## Что умеет

- 🎬 Зал IMAX-формата: изогнутый экран из 15 сегментов, 6 рядов кресел, неон,
  лампы, красная дорожка.
- 🔗 Ссылку на видео вставляешь **сенсором на телефоне** (кнопка «📋 Вставить» —
  подхватывает буфер обмена), фильм сразу играет на большом экране зала.
  Поддержка: YouTube (watch / youtu.be / shorts / live), прямые .mp4 / .webm /
  .m3u8 / .mov и любые другие страницы.
- 🎛 Пульт за спиной (поверни голову назад):
  - 💡 Свет — включить/выключить свет в зале
  - ⏪ БЛИЖЕ / ⏩ ДАЛЬШЕ — придвинуть/отодвинуть экран
  - ⏸ ПАУЗА / ▶ ИГРАТЬ — остановить и продолжить видео
  - 🔊 ГРОМЧЕ / 🔉 ТИШЕ — громкость
  - ⏪ −10с / ⏩ +10с — перемотка
  - 🔁 СНАЧАЛА — сначала
  - 🔗 ССЫЛКА — вернуться на телефон и вставить другую ссылку
  - 🎚 НАСТРОЙКИ — IPD, дистанция экрана, свет
  - 🚪 ВЫХОД — выйти из зала
- ✋ Виртуальная кисть следует за твоей настоящей рукой — по ней видно, куда
  смотришь и что нажимаешь. Нажатие — щипок (средний + большой).
- 🎚 Настройки шлема: межзрачковое расстояние 52–76 мм, дистанция до экрана,
  свет. Профиль сохраняется между запусками.

## Как собрать

1. Залей папку в репозиторий GitHub (или свой Mac/Xcode).
2. На GitHub: Actions → «Build HandAR Кино IPA» → дождись сборки →
   скачай артефакт `HandARCinema-IPA`.
3. Помести `HandARCinema-unsigned.ipa` на iPhone через ESign и установи.
4. На телефоне открой приложение, вставь ссылку, нажми «▶ В ЗАЛ»,
   вставь айфон в VR-шлем (В РЕЖИМЕ ЛАНДШАФТ — приложение только landscape).

## Как смотреть

1. Сядь поудобнее, вставь телефон в шлем экраном к лицу.
2. Вставь ссылку и нажми «▶ В ЗАЛ».
3. Поверни голову: впереди — огромный экран, за спиной — пульт.
4. Пульт: поднеси руку к кнопке, щипок. Готово.

## Структура

```
HandARCinema/
  AppDelegate.swift          — запуск и звуковая сессия
  CinemaViewController.swift — интерфейс, зал, пульт, ввод, рендер
  VRHallEngine.swift         — стерео-движок: ARKit + Vision + Metal
  Info.plist
HandARCinema.xcodeproj/      — проект Xcode
Scripts/                     — сборка IPA
.github/workflows/           — сборка на GitHub Actions
```

Приложение не зависит от HandAR Browser — можно ставить рядом.
