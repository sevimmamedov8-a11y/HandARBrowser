# HandARBrowser V15 — safe camera startup

Переработан поток запуска камеры для iPhone: приложение больше не запрашивает камеру и не конфигурирует AVCaptureSession из `viewDidLoad`. Сначала создаётся интерфейс. После START проверяется статус разрешения; после выдачи доступа камера конфигурируется на отдельной последовательной очереди, затем на главном потоке создаются preview layers и запускаются движение и Vision.

Также убран force-cast Core Motion, добавлены явные сообщения об ошибках камеры и дополнительные CI-проверки.

Полную сборку iPhoneOS в этой Linux-среде выполнить нельзя; ZIP предназначен для GitHub Actions на macOS.
