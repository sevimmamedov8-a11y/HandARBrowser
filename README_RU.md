# HandAR Vision — V16

Камера запускается автоматически после выдачи разрешения iOS. Приложение использует один `AVCaptureVideoPreviewLayer` на весь экран как живой фон, а два браузерных окна накладываются поверх него для VR-очков. Это сделано специально, чтобы не зависеть от двух параллельных preview layers одной AVCaptureSession.

Что есть в V16:
- задняя камера сразу после разрешения;
- индикатор состояния камеры;
- два одинаковых браузерных окна для левого и правого глаза;
- курсоры обеих рук;
- указательный палец — курсор;
- pinch — нажатие/перетаскивание;
- CENTER — калибровка поворота;
- BROWSER — скрыть/показать браузер;
- CAM — повторный запуск камеры;
- строка URL сверху;
- обработка ошибок и прерываний AVCaptureSession.

Название приложения на iPhone: **HandAR Vision**.

## Важно
Полная сборка iPhoneOS выполняется GitHub Actions на macOS. В этом окружении можно проверить структуру проекта и синтаксис Swift, но нельзя честно заявлять, что APK/IPA физически протестирован на конкретном устройстве.
