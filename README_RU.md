# Hand AR Browser — V10

Телефон превращается в простую AR-систему для телефонных VR-очков с двумя линзами.

## Что умеет

- Задняя камера телефона показывает реальный мир.
- Экран делится на два одинаковых глаза, чтобы изображение можно было смотреть через две линзы.
- В каждом глазу показывается интерактивный `WKWebView`.
- Core Motion отслеживает поворот телефона до 120 Гц и удерживает браузер относительно исходного направления после калибровки.
- Vision распознаёт до двух рук и отдаёт их handedness: физическая левая рука = LEFT, физическая правая = RIGHT.
- Указательный палец — указатель.
- Сведение большого и указательного пальцев — клик.
- Удержание pinch + движение по вертикали — прокрутка.
- Оба WebView синхронизируют URL и прокрутку.
- У каждого глаза есть небольшое межглазное смещение браузерной панели.

## Почему без сторонних SDK

Для iPhone 13 здесь используются системные Apple API: AVFoundation для камеры, Vision для позы руки, Core Motion для ориентации и WebKit/WKWebView для браузера. Vision документирует handedness (`chirality`) у `VNHumanHandPoseObservation`, а Core Motion даёт fused device attitude/rotation rate. Apple рекомендует `WKWebView` для встроенного веб-контента. См. официальные источники в `SOURCES.md`.

## Запуск на iPhone 13

1. На Mac открой `HandARBrowser.xcodeproj` в Xcode.
2. В Target → Signing & Capabilities выбери свою Apple ID/Team.
3. Поставь iPhone 13 как устройство запуска.
4. Запусти приложение один раз и выдай доступ к камере.
5. Введи URL и нажми START.
6. Поставь телефон в очки так, чтобы задняя камера была открыта шторкой.
7. Посмотри прямо и используй `CENTER` для повторной калибровки.

## IPA

Настоящий installable IPA требует Apple-кодовой подписи. На этом сервере нет macOS/Xcode, поэтому я не выдаю фиктивный IPA и не буду притворяться, что он собран.

В `Scripts` есть:

- `BUILD_UNSIGNED_IPA.command` — архивирует приложение без подписи.
- `BUILD_SIGNED_IPA.command` — сборка с твоим Team ID при наличии Xcode и подписывающих профилей.
- `CHECK_PROJECT.command` — проверяет структуру до сборки.
- `DOWNLOAD_DEPENDENCIES.bat` — проверяет, что внешние зависимости не нужны; все требуемые API системные.

Также есть GitHub Actions workflow для сборки unsigned IPA на `macos-latest`.

## Ограничения

Это не Apple Vision Pro и не настоящий оптический AR headset. Обычная одна задняя камера не даёт полноценного метрического 6DoF окружающего мира, поэтому перенос браузерного окна выполняется по ориентации Core Motion. Позиционный сдвиг телефона в пространстве специально не заявляется как точный world tracking.

Качество hand tracking зависит от освещения, расстояния до камеры и того, насколько обе руки остаются в поле зрения.

## Для пользователя без Mac

Самый простой путь без Mac: загрузить содержимое этого архива в GitHub-репозиторий `HandARBrowser` и дождаться workflow `Build HandARBrowser IPA`. Он запускается автоматически после push в `main`, а также вручную через `Actions → Run workflow`.

Результат: artifact `HandARBrowser-IPA` с файлом `HandARBrowser-unsigned.ipa`. Подпиши его своим ESign.
