# V29 technology notes

Системные компоненты:

- **ARKit** — world tracking, `ARSession`, `ARAnchor`, кадры камеры.
  `ARCamera.viewMatrix(for:)` даёт позу головы, `unprojectPoint(_:ontoPlane:)`
  кладёт луч пальца на плоскость панели.
- **SceneKit** — одна `SCNScene` с панелью браузера, два `SCNRenderer`
  рендерят её с точек зрения левого и правого глаза в офскрин-текстуру.
- **Metal / MetalKit** — `MTKView` как поверхность вывода, финальный проход с
  barrel-предыскажением под линзы, компенсацией хроматики и конверсией
  YCbCr→RGB для сквозного видео. Шейдер собирается в рантайме через
  `MTLDevice.makeLibrary(source:)`.
- **Core Video** — `CVMetalTextureCache` отдаёт плоскости Y и CbCr кадра ARKit
  прямо в шейдер, без копирования.
- **Vision** — `VNDetectHumanHandPoseRequest`, отслеживание кисти и щипка.
- **WebKit** — один `WKWebView`; его снимок становится текстурой панели.

Идея архитектуры: виртуальный браузер — пространственное окно с мировой
позицией, а не HUD. Стерео рождается из двух камер на реальном межзрачковом
расстоянии, смотрящих на одну сцену через асимметричные фрустумы, построенные
из физической геометрии шлема. RealityKit из проекта убран: `SCNRenderer` даёт
прямой контроль над матрицей проекции каждого глаза, без чего VR не собрать.
