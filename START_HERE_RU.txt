HANDAR VISION V29 — настоящий VR-режим

Что изменилось: split-screen заменён на полный стереоконвейер.
Асимметричные фрустумы под линзы, barrel-предыскажение в Metal,
сквозное видео отдельно для каждого глаза, панель браузера одна
и закреплена в мире. Подробности — в README_RU.md.

Как собрать:
1) Содержимое этой папки помести в корень репозитория HandARBrowser
   (файлы перезаписать, папку .git из архива не копировать).
2) GitHub Desktop: Commit Summary = V29: real VR stereo pipeline
3) Commit to main -> Push origin.
4) GitHub -> Actions -> Build HandAR Vision IPA.
5) Скачай artifact HandARBrowser-IPA, внутри HandARBrowser-unsigned.ipa.
6) Подпиши через ESign или аналог.

Файлы, которые изменились:
- HandARBrowser/MainViewController.swift   (переписан целиком)
- HandARBrowser/Info.plist                 (версия 1.1 / build 29)
- HandARBrowser.xcodeproj/project.pbxproj  (+ Metal, MetalKit в OTHER_LDFLAGS)
- Scripts/CHECK_PROJECT.command            (проверки под новую архитектуру)
- .github/workflows/build-ipa.yml          (название сборки)
- README_RU.md, PROJECT_NOTES_RU.md        (документация)

Не изменились: AppDelegate.swift, WebInput.js, index.html, остальные скрипты.
