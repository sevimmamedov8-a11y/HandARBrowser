HAND AR BROWSER V10

1) Это полностью новая чистая версия проекта. Старую HandARBrowser_V1 не удаляй.
2) Распакуй этот архив. Содержимое папки HandARBrowser_V1 помести в локальную копию репозитория HandARBrowser, сохранив .git только из репозитория.
3) Commit + Push origin.
4) GitHub -> Actions -> Build HandARBrowser IPA.
5) Дождись зелёной галочки. В Artifacts скачай HandARBrowser-IPA.zip.
6) Внутри находится HandARBrowser-unsigned.ipa. Его можно подписать через ESign.

V10 исправляет:
- invalid PBXProject rootGroup;
- xcodebuild -derivedDataPath incompatibility;
- missing configureLandscapeConnection in CameraManager;
- explicit self capture semantics for HandTracker semaphore;
- current AVFoundation mirroring API;
- current videoRotationAngle API without deprecated orientation usage in the normal iOS 17+ path.

TOM4OS не используется.
