# HandARBrowser V64 — обновлённый VR Desktop

## Интерфейс домашнего экрана в VR

Переработан `vrDesktopHTML` — домашнее меню, которое открывается при входе в шлем.

- **Живой фон**: анимированная «аврора» (три дрейфующих цветных пятна), звёздное поле и виньетка по краям вместо плоской заливки.
- **Статус-строка**: крупные часы с датой на русском, фирменный логотип HANDAR VISION, «чипы» VR BOX / заряд / VR.
- **Приветствие**: заголовок «Добро пожаловать» с подзаголовком.
- **Поиск**: стеклянная строка с пробегающим бликом.
- **Иконки приложений**: объём (внутренний блик + нижняя тень), цветное свечение под каждым цветом, hover-подъём и свечение, сжатие при нажатии, каскадная анимация появления.
- **Док**: центрированная стеклянная панель со светящимся отражением снизу. Исправлен дублирующийся SVG у иконки «Настройки».

## Контракт сохранён

`post(id)`, `data-id`, обработчик `handarApp`, элементы `#time`, `#battery`, `#controllerState` без изменений — логика `openVRApp` / `updateVRDesktopStatus` не менялась.
