# HandAR Vision V68 — исправления

## Изменения
- Ошибка AVPlayer освобождает плеер и разблокирует снимки страницы.
- Устаревшие события загрузки плеера и пробника игнорируются после смены сеанса.
- При повторном входе в кинотеатр предыдущий плеер освобождается.
- Завершение видео обновляет состояние воспроизведения; наблюдатели снимаются при освобождении.
- Асинхронные снимки не заменяют AVPlayer и не возвращают старую страницу после навигации.
- Прокси обработчиков WebKit разрывают цикл сильных ссылок.
- Текстуры камеры удерживаются отдельно для каждой отправленной GPU-команды.
- Тап создаёт одно событие click; перетаскивание, включая возврат к началу, не создаёт click.
- Перемотка ограничена длительностью; нечисловые значения перемотки и громкости отклоняются.
- Распознавание YouTube проверяет домен и идентификатор ролика.
- Прямыми нативными источниками считаются MP4, M4V, MOV и M3U8; расширение берётся из пути URL.
- Кнопка громкости передаёт команду странице, если нативный плеер не активен.
- Проверка IPA читает plist через plutil и подходит для бинарного plist.
- Проверка Swift охватывает все исходники и завершается ошибкой при ошибке синтаксиса.
- Номер сборки: 68. Обновлены стартовая инструкция и название workflow.

## Ограничения и проверка на устройстве
Проверка синтаксиса не заменяет проверку типов с Apple SDK. Сборка Xcode, запуск
GitHub Actions и проверка на физическом iPhone здесь не выполнялись.
Нельзя гарантировать отсутствие всех ошибок без этих проверок.

Нативный кинотеатр требует доступного и поддерживаемого AVPlayer URL. Пробник
не преобразует blob/DRM, не извлекает видео из недоступных вложенных документов
и не переносит авторизацию WebKit в AVPlayer. Поэтому универсальное воспроизведение
YouTube не заявляется. Возврат к снимкам страницы не обеспечивает захват аппаратного видео.

На iPhone проверить: прямой MP4/HLS; недоступный поток; окончание ролика;
повторный вход/выход при загрузке; жесты клика и прокрутки; калибровку и стерео;
длительную работу камеры и переключение приложений.
Исторические release notes описывают предыдущие версии.
