# HandAR Vision V71 — рывки меню и контраст

- Очереди обновлений камеры и рук объединены: ожидающий обработчик получает последний
  образец, промежуточные не накапливаются при занятости главного потока.
- Снимок главного экрана уменьшен с 1280 до 960 пикселей по ширине. При неизменном
  соотношении сторон это на 43.75% меньше пикселей; это не измерение ускорения приложения.
- В главном меню масштаб offscreen-рендера ограничен 1.0 вместо стандартного 1.2;
  для других режимов остаётся прежняя политика качества и перегрева.
- Убрана дополнительная постановка обработки готового снимка в очередь главного потока.
- Неподвижное наведение реже передаётся через WebKit; нажатия и отпускания не ограничены.
- На главном экране убраны backdrop blur, SVG drop-shadow и анимации появления.
  Стеклянный градиент сохранён, а увеличение иконки при наведении уменьшено.
- Контраст смягчён цветами и лёгкой серой вуалью, без отдельного CSS-фильтра:
  цветные иконки менее насыщенные, белые основания приглушены, тени и блики слабее.

Проверки: синтаксис пяти Swift-файлов, JavaScript главного экрана, семь тестов ввода,
тесты DOM-оптимизации, 124 статические проверки — успешно.
Сборка с Apple SDK и профиль CPU/GPU на iPhone не выполнялись; устранение фризов
на устройстве пока не подтверждено. Swift runtime-тесты выполняются в macOS CI,
локальный Windows toolchain не содержит доступной стандартной библиотеки.
