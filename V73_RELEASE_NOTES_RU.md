# V73 — прямой запуск YouTube в веб-режиме

Для https://youtu.be/LnFf8iFs0a8?si=PX3WwRLuzdupfdnN роутер создаёт
https://m.youtube.com/watch?v=LnFf8iFs0a8 и сразу включает живой стереовеб-плеер.
Ожидание прямого URL и принудительный embed для ссылок YouTube убраны.
Параметр общего доступа si отбрасывается; время t/start сохраняется.

Добавлены проверки исходной ссылки, времени, Shorts и отклонения чужого домена/неверного ID
на реальной Swift-функции в macOS CI. Локально выполнены проверки синтаксиса Swift,
тесты ввода и разделения аудио глаз. Runtime-тесты Swift и запуск на iPhone здесь
не выполнялись. Открытие публичной страницы подтвердило адрес и название ролика,
но не воспроизведение в WKWebView. Возможные ограничения сайта/автозапуска остаются.
Это резервный стереовеб-режим без видимого 3D-зала, как описано в V72.
