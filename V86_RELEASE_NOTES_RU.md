# V86 — кулак, свайпы меню и направление кинотеатра

## Управление рукой

К прежнему распознаванию согнутых пальцев добавлено распознавание скрытых пальцев. Сначала эта же левая или правая рука должна показать полный свежий скелет, затем пропадание кончиков пальцев при уверенно видимой ладони подтверждается примерно 0,23 секунды. Опираемся на свежие суставы Vision, а не на сохранённые точки визуального скелета. Ненадёжная ладонь, край кадра и потеря всей руки отменяют распознавание; щипок не превращается в захват. Скрытые пальцы не дорисовываются в маске переднего плана.

В меню приложений открытая ладонь перелистывает страницы: движение влево — следующая, вправо — предыдущая. Нужны четыре видимых вытянутых пальца и отчётливое горизонтальное движение. За один взмах выполняется одно перелистывание. После короткой остановки ладони можно провести в обратную сторону. Медленное смещение, вертикальное движение, смена руки и потеря отслеживания не должны перелистывать страницы.

Во время распознанного свайпа отменяются клики и удержание курсора; маска руки продолжает обновляться. Пункт управления и другие разделы меню не перелистываются скрытно. Подтверждение звучит только при фактической смене страницы. Кнопки-точки страниц сохранены.

## Кинотеатр

При входе направление берётся из свежего кадра камеры. Если камера ещё запускается, зал выравнивается по первому текущему кадру, а не по сброшенной нулевой матрице. Центр экрана находится прямо перед телефоном на высоте камеры; зал остаётся горизонтальным. После входа зал закреплён, повороты головы продолжают работать. Команда центрирования контроллера в кинотеатре вновь ставит экран перед текущим направлением телефона.

Перемещение по залу и кнопки шагов удалены по последнему уточнению пользователя. Источник изображения для глаз остаётся один.

## Проверки

Добавлены и подключены к GitHub Actions:

- Tests/check_menu_gestures.py — 413 проверок состояния скрытых пальцев и свайпа, включая дрожание, паузу, оба направления, смену рук и повторное появление.
- Tests/check_cinema_alignment.py — 444 проверки фактических методов выравнивания с заменителями платформенных матриц/узлов: разные положения и направления телефона, уровень экрана, вертикальное направление и восстановление начальной позы.
- Расширены проверки реального метода HandTracker.sample: скрытые пальцы, потеря ладони, повторное появление частичного скелета, отпускание и свежая открытая ладонь.

Полный регрессионный набор: 26/26 команд. Также проверены настоящий HTML главного меню в Edge (перелистывание, точки, границы, открытый пункт управления и другой раздел) и 128 статических проверок проекта.

На iPhone 13 с VR BOX 3 ещё нужно проверить комфортные пороги свайпа на камерах 0,5×/AR 1×, распознавание скрытых пальцев при разном освещении, захват и отпускание панели, вход в кинотеатр из обычного меню и уже работающего VR в обоих поворотах экрана. На Windows нет iOS SDK: здесь выполнены проверка синтаксиса Swift, исполняемые проверки логики с заменителями API и браузерные проверки, а не полноценная сборка и проверка камеры на устройстве.
