# V91 — загрузка YouTube и восстановление в зале

Исправлены подтверждённые проблемы приложения вокруг загрузки и отображения ошибок. Конкретный код ошибки YouTube пользователь не сообщил, поэтому воспроизведение его случая на iPhone пока не подтверждено.

- Главная YouTube, поиск и плейлисты сразу открываются в живом WKWebView внутри экрана зала. Убрано предварительное ожидание до 8 секунд в пробнике прямого потока для этих страниц.
- Растягивается только выбранный video. При исчезновении видео, ошибке или новом незагруженном плеере снимается прежний режим растягивания, чтобы чёрный видеослой не скрывал сообщения страницы.
- Видимый текст ошибки YouTube передаётся в статус зала даже при отсутствии элемента video. Скрытые старые сообщения игнорируются.
- После 20 секунд без готового видео появляется пояснение и действие «Обновить» вместо «Сначала» на правом пульте. При сетевой ошибке оно доступно сразу. Возобновившееся воспроизведение возвращает кнопку «Сначала».
- «Обновить» запускается только пользователем. Удержание/щипок отменяются перед загрузкой, чтобы не перенести старое нажатие в новую страницу. При блокировке автозапуска предлагается «Смотреть», а не перезагрузка.
- Сохранены один видеоплеер, один источник звука и копирование левого глаза в правый. Изменения не обходят ограничения доступа к видео на стороне YouTube.

Проверки: новые 18 сценариев статуса/тайм-аута/ручного повтора/устаревшего ответа; тесты JavaScript дополнены восстановлением CSS после ошибок и смены ролика; проверки URL дополнены главной, поиском и плейлистами. Выполнены проверки навигации, звука, геометрии зала, управления комфортом и монокопирования, Swift parser и git diff --check.

На Windows нет iOS SDK: IPA и реальную загрузку YouTube на iPhone 13 требуется проверить после сборки V91. Проверить вход в зал без ссылки, поиск ролика, ошибочную ссылку, отключение/возврат интернета и «Обновить» на пульте. Если ошибка повторится, её точный текст теперь должен быть виден.
